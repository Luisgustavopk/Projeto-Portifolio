# Arquivos de áudio

Coloque aqui os arquivos das 3 faixas do popover de música, com estes nomes exatos:

- `track-1.mp3` — Down by the River (Baldur's Gate 3 OST)
- `track-2.mp3` — Save Room / Secure Place (Resident Evil OST)
- `track-3.mp3` — Binks' Sake (Acoustic Vinyl) (One Piece OST)

Use apenas arquivos que você tenha o direito de usar (compra própria, trilha royalty-free, etc.) — essas três são música comercial licenciada, então não vieram incluídas no projeto.

Se preferir trocar por outras músicas, é só editar `src/data/tracks.js` (campos `title`, `source` e `src`).
